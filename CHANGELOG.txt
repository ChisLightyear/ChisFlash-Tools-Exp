ChisFlash Water Client 2.046 r27 is a Windows x64 preview. Extract the ZIP and run ChisFlashWaterClient.exe. The .NET runtime is included. The empty covers/ folder is for your own artwork.

- GBA programming follows the selected cartridge profile when the NOR responds, including chips with an unknown model or a missing menu directory. A valid WaterLink mapping can rebuild the game list and retain fragmented block order.
- Adding a menu over a single GBA game now offers to export the original ROM. Choose the export size and save location, or skip export. Programming starts when you click Start Burn.
- GBA multicart burns report erase and programming times separately. Programming speed uses the image size and time spent in the programming phase. When blank sectors are skipped, the log also shows how much data was sent.
- Updated English messages for menu rebuilding, ROM export and programmer errors.

Verified with offline cartridge simulations and protocol checks.
