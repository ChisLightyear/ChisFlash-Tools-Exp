# GBC Chinese fonts / GBC 中文字库

Chinese menus require a **12px** font. Supply your own TTF, OTF or BDF in this directory and reopen the tool. Select the font in the Client's menu preview or the Builder's Chinese Font list.

TTF/OTF filenames must contain `12px` or `_12`, such as `myfont_12.ttf`. BDF files must declare a 12px glyph size in their contents. 8px fonts and TTF/OTF files without a size marker are rejected. English menus use their built-in font.

No external font files are distributed in this package. Follow your font's licence.

中文菜单必须使用 **12px** 字库。请自备 TTF、OTF 或 BDF 文件，放入本目录后重新打开工具。在上位机菜单预览或合卡器的中文字库列表中选择。

TTF/OTF 文件名必须含 `12px` 或 `_12`，例如 `myfont_12.ttf`。BDF 文件内部声明的字形尺寸必须为 12px。8px 字库及没有尺寸标记的 TTF/OTF 不予接受。英文菜单使用内置字库。

本包不分发外部字体文件，请遵守自备字体的许可。
