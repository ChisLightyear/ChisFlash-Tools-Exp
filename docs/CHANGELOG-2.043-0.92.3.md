# 上位机2.043／合卡器0.92.3

日期：2026-10-07。上位机新增MBC5 MAX 32M的菜单＋16游戏固定槽位工作区；合卡器版本保持0.92.3。

- MAX 16in1从完整成品镜像模式改为逐槽操作，复用8M的导入、替换、删除、整卡扫描、逐槽导出、完整镜像导出和NOR擦写校验流程。
- 核对实际固定固件和菜单：菜单预留1M、游戏1为1M、游戏2～16各2M、每游戏32K SRAM。MAX不使用8M第三槽扩容逻辑。
- 8M、32M分别保存工作区，切换卡型使旧设备扫描失效；RTC仍保留完整成品镜像流程。
- 识别已知标准菜单及确切的无GB头EX 1.02菜单，未知无头文件不接受。菜单ROM和固件未修改，也未加入交付包。
- 批量导入按完整布局一次验证，冲突不覆盖原内容；完整32M NOR写入保留SRAM，写前检查真实几何，启动区域最后写，所有bank读回校验。
- 修复后台导入结束时跨线程刷新表格导致窗口阻塞的问题；固定槽位刷新回到UI线程，重建期间避免选择/尺寸事件重入。
- MAX布局、模拟NOR、完整窗口导入及实际EX菜单识别145项，原8M 625项及选型36项检查通过。
- 固定模式存档管理尚未接入。验证仅使用模拟设备和合成ROM，不声明实卡验收；本地交付，未推送远程。
