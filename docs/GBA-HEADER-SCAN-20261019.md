# 恢复GBA主按钮游戏头扫描

上位机2.046 r11。

2.046 r12补充单卡芯片：原始ID属于已收录256Mbit NOR型号且容量为32 MiB时，只读取地址0的单ROM头，类型自动切到单卡，合卡入口禁用。此类单卡不必再读取合卡配置即可准备原ROM写入；未知ID及GB/GBC不应用该判定。

“分析卡带”在读取NOR ID、CFI、容量后，对大于32 MiB的GBA卡按4 MiB扫描游戏头，日志列出位置、标题和游戏代码。盖中盖兼容路径使用现有bank切换和头部读取实现，结束后回到bank0；水线沿用既有地址读取路径。

目录和存档没有在此入口读取。扫描结果分别记录“游戏头已扫描”和“配置尚未分析”，菜单行显示“未分析”；地址0的有效单游戏仍可显示，其他位置头部不被拼成合卡目录。完整目录及存档分析保留在“卡带 → 分析配置”。小于等于32 MiB的外部探测及GB/GBC探测规则不变。

对照基准为`FPGA-DMG-01/丐中丐/上位机/ChisFlashBurner/mission_gba.cs`的`mission_readRomID`，其功能为NOR ID、CFI和大容量头部扫描。此前比较中使用的`beggar_socket-main/client/ChisFlashBurner/mission_gba.cs`还包含菜单、SPI状态和A/B存档等扩展，不能将这些视为原版盖中盖已有功能。本次不移植这些扩展。

验证：37项生产扫描流程模拟检查，覆盖大容量GBA恢复头部读取、普通容量边界、空头部、未读取目录与存档、GB路径保持原状；20项扫描与真实窗体检查，覆盖地址0游戏显示、目录未分析标记及擦写入口限制。未连接或擦写实卡。
