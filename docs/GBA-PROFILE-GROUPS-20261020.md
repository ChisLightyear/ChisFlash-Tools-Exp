# GBA 烧录卡类型分组

上位机2.046 r14。GBA下拉框按“——合卡——／——单卡——”分组，保留原窗口布局。分组标题不可选，键盘上下、首尾和滚轮导航跳过不可用项目；点击标题或待确认型号不会切换工作区。

r15补充：在原生下拉列表处理鼠标前拦截分组标题和待确认型号的悬停、按下、松开及双击。点击这些行不高亮、不收起列表，也不触发类型切换。已使用实际下拉窗口发送鼠标消息验证，具体型号仍可正常点击选择；60项界面及单游戏检查通过。

合卡组沿用当前烧录器和卡型允许的既有选项，包括普通电池／铁电、免电、水线、多NOR及已识别的01G/02G碎片管理类型。

单卡组包括通用单卡、ChisFlash 1.0 FRAM、1.1 FLASH无时钟、1.1 FLASH时钟、1.2 FRAM震动及既有1.0V。1.1V先标注待确认，保持不可选。识别到256系列单卡芯片时只显示单卡组，不提供合卡类型；具体存档硬件／RTC由用户选型，NOR ID不用于猜测这些差异。

本轮只整理类型选择。新增单卡型号复用原ROM单卡流程，单游戏列表、文件范围、容量及只读限制沿用既有规则；未新增FLASH ID兼容补丁、SRAM转换、RTS补丁或RTC配置。既有1.0V保持其原ROM处理流程。GB/GBC容量候选规则保留。

验证：51项真实控件及单游戏回归，89项GB/GBC选型及模拟NOR回归通过。另对照r5检查14个原控件的可见性、父容器及所有可见控件的位置和尺寸；隐藏AutoSize控件未布局时不比较几何。分组预览由实际下拉控件和实际候选项绘制。本次未连接或擦写硬件。
